# Тест на создание заказа и на получение заказа по треку заказа с помощью API Яндекс.Самокат.
Автоматизация теста к API
1.Клиент создает заказ.
2.Проверяется, что по треку заказа можно получить данные о заказе.

Шаги автотеста:
1.Выполнить запрос на создание заказа.
2.Сохранить номер трека заказа.
3.Выполнить запрос на получение заказа по треку заказа.
4.Проверить, что код ответа равен 200.

- Для запуска тестов должны быть установлены пакеты pytest и requests - Pip install requests - Pip install pytest
- Запуск всех тестов выполняется командой pytest
